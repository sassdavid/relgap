## relgap completion tcsh

Generate the autocompletion script for tcsh

### Synopsis

Generate the autocompletion script for tcsh. carapace, built into relgap, writes it.

Add this line to ~/.tcshrc:

  eval `relgap completion tcsh`


```
relgap completion tcsh [flags]
```
