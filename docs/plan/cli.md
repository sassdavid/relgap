# relgap: CLI surface

The `docs/cli/` reference is generated by cobra; this file is the design contract.

## Commands

| Command | Purpose | Milestone |
|---|---|---|
| `relgap digest <tool> <from>..[<to>]` | merged notes for a version range | M2–M4 |
| `relgap digest --from-mise [path]` / `--all [path]` | digest every outdated pin of the project (mise config pins only, or all), using the ranges `outdated` shows | M6 |
| `relgap digest --base <ref> [--head <ref>] [path]` / `--pull-request [path]` | digest the exact pins a change upgrades, base version to head version; `--pull-request` reads the GitHub Actions event and narrows a Renovate pull request to the dependency its branch names ([output-and-ci](specs/output-and-ci.md)) | M14, v0.3.0 |
| `relgap outdated [path]` | project table: tool, current, latest, versions behind, breaking and deprecation counts, pin location ([ADR-0009](adr/0009-outdated-current-and-latest.md)); EOL and vuln columns ([enrichment](specs/enrichment.md)); `--binaries` adds the OSV vulnerabilities of installed Go executables | M6; EOL/vulns M8 |
| `relgap drift [roots…]` | version matrix: a row per repository, a column per drifting tool ([ADR-0010](adr/0010-drift-offline-matrix.md)); `--tool`, `--latest`, `--drift-ignore-constraints`, `--submodules`; `--from-tfcensus <file>` adds a row per tfcensus unit ([ADR-0014](adr/0014-drift-from-tfcensus.md)) | M7; tfcensus M18 |
| `relgap pins [roots…]` | raw list of discovered pins with locations (debugging and scripting); `--unresolved`, `--submodules`, `--renovate-report <file>` | M5 |
| `relgap resolve <tool>` | show how a tool resolves: repo, scheme, sources, EOL/OSV ids | M1 |
| `relgap registry lint [file…]` / `registry test <tool\|file.yaml> <range>` | for registry contributors: lint checks the schema, regexes, placeholders, hosts and selectors; test digests a range once per source | M1 (lint), M8 (test) |
| `relgap registry update` | download the newest `registry/*.yaml` from relgap's main branch; they replace the embedded entries of the same name | M17 |
| `relgap mcp` | stdio MCP server | M10 |
| `relgap notify --from <json> --notify github-pr-comment` | one comment per report kind on a GitHub pull request, from saved digest, outdated or drift JSON | M13 |
| `relgap cache info\|clear\|prune` | inspect or clear the cache | M4 |
| `relgap config show [--sources]\|path\|validate\|init` | configuration; `init [path] [--user] [--force]` writes a commented template | M0/M8, init M16 |
| `relgap completion <shell>`, `relgap version` | standard | M0 |

`digest` also takes `--include-prereleases` (on when from or to is itself a prerelease) and `--summarize`
(the provider comes from `llm.provider` or `RELGAP_LLM_PROVIDER`, [specs/mcp-and-llm.md](specs/mcp-and-llm.md)).
`digest` takes `--only <kind>` (repeatable or comma-separated: breaking, deprecation, security,
feature, fix, other). It lists only those entries, in every digest mode, while the counts and
`--fail-on` still cover every kind. It's a `digest` flag, not a global one: the other commands
list no entries.

## Arguments & range syntax
- `<tool>` is a name or alias, resolved through the registry: `terraform`, `tf`, `aqua:hashicorp/terraform`, `github:owner/repo`, `tfprovider:hashicorp/aws`, `chart:argo/argo-cd`.
- `digest <tool>` takes two arguments, the tool and a range: `A..B` (A excluded, B included) or `A..` (to the latest stable version on the release line). There is no `..B` form and no digest without a range; `--from-mise` and `--all` digest from the current pins.
- `--line none|major|minor` sets the release line `A..` ends on, e.g. `relgap digest helm 3.19.0.. --line major`. Without the flag, the tool's `version.line` applies (default `none`).

## Global flags

| Flag | Default | Notes |
|---|---|---|
| `--format tty\|plain\|md\|json\|sarif\|github` | tty if TTY else plain | sarif and github (annotations) only for `outdated`/`drift` |
| `--out <format>=<path>` (repeatable) | none | `digest`, `outdated`, `drift`, `pins`: also write the report to a file in another format, same exit code (M13, [engineering ADR-0014](../engineering/adr/0014-report-outputs-and-pr-comment.md)). Replaces the planned `-o, --output` |
| `--md-max-chars <n>` | 60000 | cut Markdown at a row or section boundary with a footer; 0 means no limit (M13) |
| `--min-confidence <0..1>` | 0.5 | hides keyword-only guesses |
| `--fail-on breaking\|deprecation\|eol\|vuln\|drift\|outdated` (repeatable) | none | exit 3 when matched. Command flag: `outdated` checks `breaking`, `deprecation`, `eol`, `vuln` and `outdated`, `digest` checks `breaking` and `deprecation`, `drift` checks `drift` |
| `--max-behind major:N\|minor:N\|patch:N\|releases:N\|days:N` | empty (any lag) | how far behind `--fail-on outdated` allows; `outdated` only |
| `--offline` / `--refresh` / `--no-cache` | | cache modes |
| `--concurrency <n>` | 8 | GitHub requests in flight: the api.github.com host limit and the GitHub client's fan-out; 2 at most without a token |
| `--config <file>`, `-v/-q`, `--log-format`, `--color`, `--no-input` | | [engineering standards](../engineering/engineering-standards.md) |

## Examples

```sh
relgap digest terraform 1.15.8..1.17.1 --only breaking,deprecation
relgap digest claude-code 2.1.300..        # to the latest release
relgap digest tfprovider:hashicorp/aws 5.100.0..6.72.0 --format md > notes.md
relgap outdated --fail-on eol --fail-on vuln --format github --out sarif=relgap.sarif --out json=outdated.json
relgap notify --from outdated.json --notify github-pr-comment   # in a pull_request workflow
relgap drift ~/src/infra --tool terraform --tool terragrunt
relgap pins . --format json | jq '.data.pins[] | select(.tool=="hk")'
```

## Exit codes
Shared contract ([engineering-standards.md](../engineering/engineering-standards.md#errors--exit-codes)):
- 3 = `--fail-on` matched
- 1 = at least one tool errored, partial output still printed, and no `--fail-on` value matched.
  3 wins over 1 ([ADR-0012](adr/0012-fail-on-gate-and-sarif.md)): a match on partial data is
  still a match. A pass on partial data is not, so a failure exits 1 when nothing matched.
- 2 = wrong usage, 4 = credentials missing or rejected for every source, 130 = interrupted.
  The full table is generated from `internal/cli/run.go` into `/reference/exit-codes`.
