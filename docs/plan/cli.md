# relgap: CLI surface

The `docs/cli/` reference is generated by cobra; this file is the design contract.

## Commands

| Command | Purpose | Milestone |
|---|---|---|
| `relgap digest <tool> [<from>..<to>]` | merged notes for a version range | M2–M4 |
| `relgap digest --from-mise` / `--all` | digest every outdated tool in this project | M6 |
| `relgap outdated [path]` | project table: current, latest, skipped, breaking count, EOL, vulns | M6 |
| `relgap drift [roots…]` | tool × repo version matrix | M7 |
| `relgap pins [roots…]` | raw list of discovered pins with locations (debugging and scripting); `--unresolved`, `--submodules`, `--renovate-report <file>` | M5 |
| `relgap resolve <tool>` | show how a tool resolves: repo, scheme, sources, EOL/OSV ids | M1 |
| `relgap registry lint <file>` / `registry test <tool>` | for registry contributors | M1 (lint), M8 (test) |
| `relgap mcp` | stdio MCP server | M10 |
| `relgap cache info\|clear\|prune` | inspect or clear the cache | M4 |
| `relgap config show [--sources]\|path\|validate\|init` | configuration | M0/M8 |
| `relgap completion <shell>`, `relgap version` | standard | M0 |

## Arguments & range syntax
- `<tool>` is a name or alias, resolved through the registry: `terraform`, `tf`, `aqua:hashicorp/terraform`, `github:owner/repo`, `tfprovider:hashicorp/aws`, `chart:argo/argo-cd`.
- The range is `A..B` (A excluded, B included), `A..` (to latest), or `..B` (from the current pin in the cwd). If omitted, it runs from the current pin to latest.
- `--line <major|minor>` stays on a release line, e.g. `helm digest --line 3`.

## Global flags

| Flag | Default | Notes |
|---|---|---|
| `--format tty\|plain\|md\|json\|sarif` | tty if TTY else plain | sarif only for `outdated`/`drift` |
| `-o, --output <file>` | stdout | |
| `--only breaking,deprecation,security,feature,fix` | all | filters entry kinds |
| `--min-confidence <0..1>` | 0.5 | hides keyword-only guesses |
| `--fail-on breaking\|deprecation\|eol\|vuln\|drift\|outdated` (repeatable) | none | exit 3 when matched |
| `--include-prereleases` | false | auto-true when from/to is itself a prerelease |
| `--offline` / `--refresh` / `--no-cache` | | cache modes |
| `--concurrency <n>` | 8 | per-tool fan-out |
| `--summarize [--llm-provider …]` | off | [specs/mcp-and-llm.md](specs/mcp-and-llm.md) |
| `--config <file>`, `-v/-q`, `--log-format`, `--color`, `--no-input` | | [engineering standards](../engineering/engineering-standards.md) |

## Examples

```sh
relgap digest terraform 1.15.8..1.17.1 --only breaking,deprecation
relgap digest claude                      # current pin in cwd → latest
relgap digest tfprovider:hashicorp/aws 5.100.0..6.72.0 --format md > notes.md
relgap outdated --fail-on eol --fail-on vuln --format sarif -o relgap.sarif
relgap drift ~/src/infra --tool terraform --tool terragrunt
relgap pins . --format json | jq '.data.pins[] | select(.tool=="hk")'
```

## Exit codes
Shared contract ([engineering-standards.md](../engineering/engineering-standards.md#errors--exit-codes)):
- 3 = `--fail-on` matched
- 1 = at least one tool errored, partial output still printed
